# RoboDog Full-Project Pseudocode

This document rewrites the executable parts of the RoboDog project as
pseudocode. It is meant for learning and presentation: it keeps the control
flow, state machines, and data movement visible without copying every low-level
implementation detail.

## Project-Wide Runtime Picture

```text
START DogVision project

IF python/main.py RUN_SPEECH_TEST_ONLY is true:
    run the speech-only TCP + Realtime test
    exit normal vision app

ELSE:
    start normal vision app
    read camera frames on the UNO Q Linux side
    run hand, face, person, and ball detectors
    convert perception result into command characters
    call Arduino Bridge functions
    Arduino sketch updates OLED / LED matrix
    Arduino sketch forwards CMD:<char> to ESP32 over Serial1
```

## sketch/sketch.ino

The UNO Q sketch is the bridge between Python and the lower-level ESP32
controller. Python calls named Bridge functions; the sketch validates those
requests and drives local displays or UART output.

### Global setup

```text
IMPORT Arduino Router Bridge
IMPORT I2C and OLED libraries
IMPORT UNO Q LED matrix library

DEFINE OLED I2C address
CREATE oled display object
CREATE LED matrix object

DEFINE three 13x8 LED matrix frames:
    smiley face
    indifferent face
    blank neutral face
```

### drawMatrixFrame(frame)

```text
FUNCTION drawMatrixFrame(frame):
    CREATE packedFrame with four 32-bit integers set to zero
    SET bitCount to 0

    FOR each row from top to bottom:
        FOR each column from left to right:
            IF frame[row][column] is on:
                word index = bitCount / 32
                bit index = 31 - (bitCount modulo 32)
                SET that bit inside packedFrame[word index]
            INCREMENT bitCount

    LOAD packedFrame into UNO Q LED matrix
```

### CameraStream

```text
CLASS CameraStream:
    FUNCTION init(path, width, height):
        OPEN camera with V4L2
        REQUEST width and height
        SET camera buffer size to 1
        IF camera did not open:
            PRINT camera error
            UPDATE OLED with "CAM FAILED"

        CREATE lock
        SET latest frame to none
        SET running flag to true
        START background update thread

    FUNCTION update thread:
        SET fail_count to 0
        WHILE running:
            IF camera is not open:
                sleep 1 second
                CONTINUE

            READ one frame
            IF read succeeded:
                RESET fail_count
                LOCK
                STORE frame as latest frame
                UNLOCK
            ELSE:
                INCREMENT fail_count
                PRINT occasional warning
                sleep briefly

    FUNCTION read():
        LOCK
        IF no frame exists:
            RETURN none
        ELSE:
            RETURN a copy of latest frame

    FUNCTION stop():
        SET running to false
        JOIN background thread
        RELEASE camera
```

### Timed camera scan helpers

```text
FUNCTION start_camera_motion(now, command, direction, state, duration_limit):
    SEND command to ESP32 through Arduino
    SET camera_scan_state to state
    STORE scan start time
    STORE direction as +1 for up or -1 for down
    STORE duration limit
    RESET hand confirmation count
    IF this is face scanning:
        schedule face recognition immediately
    MARK Python camera state as neutral/logical unknown

FUNCTION start_camera_scan(now):
    IF camera scan state is not IDLE:
        RETURN

    RESET net timed camera offset
    IF familiar face is required:
        first scan state = FACE_SCANNING
    ELSE:
        first scan state = HAND_SCANNING

    START upward camera motion with command r

FUNCTION stop_camera_scan(now):
    IF current state is not face scan or hand scan:
        RETURN 0

    SEND scan stop command x
    COMPUTE elapsed travel time
    ADD signed elapsed time to net camera offset
    CLEAR active scan direction
    SET state to LOCKED
    STORE target last seen time
    RETURN elapsed travel time

FUNCTION start_hand_scan_below_face(now):
    remaining_down_time = max(net upward offset, 0)
    IF no downward travel remains:
        return_camera_from_scan(now)
        RETURN false

    START downward camera scan using command v
    LIMIT it to remaining_down_time
    RETURN true

FUNCTION return_camera_from_scan(now):
    IF scan state is IDLE or already RETURNING:
        RETURN

    IF currently moving:
        ADD signed elapsed motion to net offset
        CLEAR scan direction

    SEND neutral/return command n
    WAIT abs(net offset) plus settle time before accepting new scan
    SET state to RETURNING
    RESET hand confirmation count
    MARK Python camera state as neutral
```

### update_camera_scan(...)

```text
FUNCTION update_camera_scan(legs_detected, hand_detected, face_status, now):
    IF state is IDLE:
        IF legs_detected:
            start_camera_scan(now)
            RETURN message for face or hand scan
        RETURN none

    IF state is FACE_SCANNING:
        IF face_status is familiar:
            stop_camera_scan(now)
            IF hand already detected:
                RETURN "Familiar face and hand found"
            IF start_hand_scan_below_face(now):
                RETURN "Familiar face found; scanning down for hand"
            RETURN "No hand scan travel; returning"

        IF face scan exceeded timeout:
            return_camera_from_scan(now)
            RETURN timeout message

        RETURN scanning message

    IF state is HAND_SCANNING:
        IF hand_detected:
            INCREMENT hand confirmation count
            IF enough confirmations:
                stop_camera_scan(now)
                RETURN "Hand found"
        ELSE:
            RESET hand confirmation count

        IF hand scan exceeded its limit:
            return_camera_from_scan(now)
            RETURN timeout message

        RETURN upward or downward scan message

    IF state is RETURNING:
        IF return wait has elapsed:
            SET state to IDLE
            RESET net camera offset
            RETURN "Camera returned"
        RETURN "Returning camera"

    IF state is LOCKED:
        IF hand is still detected:
            UPDATE target last seen time
            RETURN "Tracking hand"
        IF target has been lost long enough:
            return_camera_from_scan(now)
            RETURN "Target lost; returning"
        RETURN "Holding camera position"
```

### main_loop()

```text
FUNCTION main_loop():
    TRY:
        frame = latest camera frame
        IF frame is none:
            RETURN
        MIRROR frame horizontally

        IF robot_state is CHASING:
            IF it is time to check manual stop:
                DETECT hands
                IF first hand points down:
                    SEND stop command
                    SET robot_state to STANDING
                    START normal command cooldown
                    UPDATE OLED "Stopped (manual)"
                    RETURN

            RUN ball_tracker.command_for_frame(frame)
            SEND returned movement command

            IF ball tracker says ball found:
                SET robot_state to STANDING
                START cooldown
                SET camera neutral
                DISPLAY standing/ball found
            ELSE IF ball tracker gave up:
                SET robot_state to STANDING
                START cooldown
                SET camera neutral
            ELSE IF no ball has ever been seen:
                DISPLAY top diagnostic object or "nothing"

            UPDATE OLED
            RETURN

        IF still inside command cooldown:
            RETURN

        INCREMENT inference counter
        IF this is not every third pass:
            RETURN

        DETECT hands
        now = monotonic time

        IF face-recognition period elapsed:
            IF currently face-scanning:
                use faster scan face period
            ELSE:
                use normal face period

            RUN face_gate.recognize(frame)
            IF face is familiar:
                update last familiar time
                show smiley matrix
            ELSE IF face is unfamiliar:
                show indifferent matrix

        SET command to none
        SET display text to "NO HAND"
        SET posture transition flag false
        SET legs_detected false

        IF standing, scan is idle, no hands, and camera check interval elapsed:
            DETECT person with YOLO
            legs_detected = person box exists and looks legs-only

        scan_display = update_camera_scan(legs_detected, hand exists, face_status, now)

        IF hands exist:
            USE first hand landmarks
            CLASSIFY folded state of index, middle, ring, and pinky
            open_palm = no fingers folded
            pointing = only index extended
            fist = all fingers folded

            IF pointing:
                COMPUTE index direction
                SET point_left, point_right, point_up, or point_down

            IF commands are not currently allowed:
                display "Ignoring (unfamiliar)"

            ELSE IF robot is STANDING:
                IF open palm:
                    command = stop
                ELSE IF point up:
                    command = walk
                ELSE IF point left:
                    command = left
                ELSE IF point right:
                    command = right
                ELSE IF point down:
                    command = sit
                    state = SITTING
                    posture transition = true
                ELSE IF fist:
                    command = stop
                    state = CHASING
                    start ball chase
                    posture transition = true
                    point camera down
                ELSE:
                    display unknown sign

            ELSE IF robot is SITTING:
                IF point down:
                    command = prone
                    state = PRONE
                    posture transition = true
                ELSE IF point up:
                    command = stand up / stop
                    state = STANDING
                    posture transition = true
                ELSE:
                    display sitting help text

            ELSE IF robot is PRONE:
                IF point up:
                    command = sit
                    state = SITTING
                    posture transition = true
                ELSE:
                    display prone help text

            IF command is not none:
                SEND command
                SET cooldown based on posture or normal command

            IF robot is standing and camera scan is idle:
                SET camera neutral

        IF robot is not STANDING:
            return_camera_from_scan(now)
        ELSE IF no command was produced and scan display exists:
            display scan message

        UPDATE OLED with display text

    EXCEPT any error:
        PRINT traceback
        return camera from scan
        SEND stop command
```

### HandGestureDetector

```text
CLASS HandGestureDetector:

        CREATE MPPalmDet for palm boxes
        CREATE MPHandPose for full hand landmarks

    FUNCTION detect(frame):

        hands = empty list

        FOR each palm:
            result = hand_detector.infer(frame, palm)

            EXTRACT handedness
            EXTRACT confidence
            ADD hand dictionary to hands

        RETURN hands
```

## python/hand_models/mp_palmdet.py

This file implements the low-level palm detector used by `detector.py`.

```text
CLASS MPPalmDet:
    FUNCTION init(model path, thresholds, backend, target):
        STORE thresholds and runtime settings
        SET input size to 192x192
        LOAD ONNX model with OpenCV DNN
        LOAD fixed MediaPipe anchor grid

    FUNCTION setBackendAndTarget(backend, target):
        STORE backend and target
        APPLY them to OpenCV DNN model

    FUNCTION preprocess(image):
        RESIZE image to 192x192 while preserving aspect ratio
        ADD black padding if needed
        CONVERT BGR image to RGB
        NORMALIZE pixels to 0..1
        RETURN NHWC input tensor and padding bias

    FUNCTION infer(image):
        PREPROCESS image
        RUN model forward pass
        POSTPROCESS outputs into palm boxes and palm landmarks
        RETURN palm detections

    FUNCTION postprocess(output_blob, original_shape, pad_bias):
        READ raw scores, box deltas, and landmark deltas
        APPLY sigmoid to scores
        CONVERT deltas and anchors into image-space boxes
        REMOVE padding bias
        APPLY non-maximum suppression
        IF nothing remains:
            RETURN empty detection array
        CONVERT selected landmark deltas into image coordinates
        RETURN rows containing box, 7 landmarks, and score

    FUNCTION load_anchors():
        RETURN the fixed anchor coordinates expected by the palm model
```

## python/hand_models/mp_handpose.py

This file estimates 21 hand landmarks from a palm detection.

```text
CLASS MPHandPose:
    FUNCTION init(model path, threshold, backend, target):
        STORE model settings and crop geometry constants
        SET input size to 224x224
        LOAD ONNX model with OpenCV DNN

    FUNCTION setBackendAndTarget(backend, target):
        STORE backend and target
        APPLY them to OpenCV DNN model

    FUNCTION cropAndPadFromPalm(image, palm_box, for_rotation):
        SHIFT palm box using configured shift vector
        ENLARGE palm box using configured scale
        CLIP box to image limits
        CROP image to palm/hand area
        PAD crop into a square
        RETURN crop, adjusted box, and padding bias

    FUNCTION preprocess(image, palm):
        CROP broad palm region
        CONVERT to RGB
        COMPUTE hand rotation from palm base to middle-finger base
        ROTATE image so hand is upright
        FIND rotated palm box
        CROP and pad final hand region
        RESIZE to 224x224
        NORMALIZE pixels to 0..1
        RETURN input tensor and transform metadata

    FUNCTION infer(image, palm):
        PREPROCESS image and palm
        RUN hand-pose model
        POSTPROCESS output back into original image coordinates
        RETURN bounding box, screen landmarks, world landmarks, handedness, confidence

    FUNCTION postprocess(model_output, transform metadata):
        READ landmarks, confidence, handedness, and world landmarks
        IF confidence is below threshold:
            RETURN none
        SCALE landmarks from model input back to crop size
        UNROTATE landmarks
        TRANSLATE landmarks back to original image coordinates
        BUILD enlarged hand bounding box
        RETURN one flattened result row
```

## python/face_gate.py

`face_gate.py` decides whether the largest visible face is familiar enough to
allow gesture commands.

```text
CLASS FaceGate:
    FUNCTION init(detector path, recognizer path, database path, input size):
        CREATE YuNet face detector
        CREATE SFace recognizer
        LOAD known face embeddings from JSON
        INITIALIZE recognition error counter

    FUNCTION load_db(path):
        IF database file is missing:
            PRINT warning
            RETURN empty dictionary
        READ JSON
        CONVERT each saved embedding list to float32 array
        RETURN name -> embedding dictionary

    FUNCTION set_frame_size(width, height):
        IF detector input size changed:
            STORE new size
            UPDATE YuNet detector input size

    FUNCTION prepare_frame(frame):
        COMPUTE scale that fits frame within 320x240 without upscaling
        IF no resize needed:
            RETURN original frame
        RETURN resized frame

    FUNCTION log_recognition_error(error):
        INCREMENT error counter
        PRINT occasional warning

    FUNCTION recognize(frame):
        TRY:
            IF frame is invalid:
                RETURN ("none", none)

            PREPARE frame
            UPDATE detector input size
            DETECT faces
            IF no faces:
                RETURN ("none", none)

            SELECT largest face
            ALIGN and crop face
            EXTRACT SFace feature

            SET best score to -1
            FOR each known person:
                COMPARE known feature with current feature
                KEEP highest score and matching name

            IF best score is at least FACE_MATCH_THRESHOLD:
                RETURN ("familiar", best name)
            RETURN ("unfamiliar", none)

        IF OpenCV or shape error occurs:
            LOG warning
            RETURN ("none", none)

FUNCTION verify_face_models():
    CREATE dummy frame
    TRY loading and running YuNet detector
    TRY loading SFace recognizer
    PRINT success or model error message
```

## python/ball_tracker.py

`ball_tracker.py` wraps YOLOv8n object detection for ball chasing and
legs-only person detection.

### Startup and prediction

```text
CLASS BallTracker:
    FUNCTION init(model_path, walk_command, stop_command, left_command, right_command):
        LOAD YOLOv8n ONNX model with OpenCV DNN
        STORE output layer names
        STORE movement command characters
        RESET counters and chase state
        VERIFY model accepts configured input size

    FUNCTION verify_model_input_size():
        CREATE blank 320x320 image
        CONVERT to DNN blob
        RUN one forward pass
        PRINT success or size mismatch warning

    FUNCTION letterbox(frame):
        RESIZE frame to fit 320x320 while preserving aspect ratio
        PAD remaining area with gray
        RETURN padded frame, scale, left padding, top padding

    FUNCTION to_frame_box(row, scale, pad_left, pad_top):
        CONVERT YOLO center-x, center-y, width, height
        INTO original-frame left, top, width, height

    FUNCTION predict(frame):
        LETTERBOX frame
        CREATE normalized blob
        RUN model forward pass
        IF forward fails:
            LOG occasional warning
            RETURN none

        SQUEEZE raw output
        IF output layout is channels-first:
            TRANSPOSE it
        ELSE IF output layout is rows-first:
            KEEP it
        ELSE:
            PRINT shape warning
            RETURN none

        RETURN predictions plus letterbox transform values
```

### detect_ball(frame)

```text
FUNCTION detect_ball(frame):
    prediction_result = predict(frame)
    IF prediction_result is none:
        RETURN none and empty diagnostic candidates

    CREATE boxes, confidences, candidates
    FOR each prediction row:
        FIND highest scoring class
        IF confidence is high enough for diagnostics:
            ADD class and confidence to candidates
        IF class is not sports ball or confidence is too low:
            CONTINUE
        CONVERT box to original frame coordinates
        ADD box and confidence

    SORT diagnostic candidates by confidence
    KEEP top diagnostic labels

    IF no ball boxes:
        RETURN none and diagnostics

    APPLY non-maximum suppression
    IF no box survives:
        RETURN none and diagnostics

    SELECT first surviving box
    RETURN ball center x, center y, radius, and diagnostics
```

### detect_person(frame)

```text
FUNCTION detect_person(frame):
    prediction_result = predict(frame)
    IF prediction_result is none:
        RETURN none

    FOR each prediction row:
        FIND highest scoring class
        IF class is person and confidence is high enough:
            CONVERT box to original frame coordinates
            STORE box and confidence

    IF no person boxes:
        RETURN none

    APPLY non-maximum suppression
    RETURN first surviving person box as left, top, right, bottom
```

### Chase state and command choice

```text
FUNCTION is_legs_only(person_box):
    RETURN true when person box begins near top edge and has enough height

FUNCTION should_check_manual_stop():
    INCREMENT counter
    RETURN true every MANUAL_STOP_CHECK_INTERVAL frames

FUNCTION should_check_camera():
    INCREMENT counter
    RETURN true every CAMERA_CHECK_INTERVAL frames

FUNCTION start_chase():
    SET ball_ever_seen false
    CLEAR last_seen_ball_side
    STORE chase start time
    STORE last ball seen time as now

FUNCTION command_for_frame(frame):
    ball, diagnostics = detect_ball(frame)
    command, display, exit_reason = decide_chase_command(ball, frame width)
    RETURN ball, diagnostics, command, display, exit_reason

FUNCTION decide_chase_command(ball, frame_width):
    frame_center = frame_width / 2

    IF ball exists:
        UPDATE ball_ever_seen true
        REMEMBER whether ball is left or right of center
        STORE last seen time

        IF ball radius is large enough:
            RETURN stop, "Ball found!", "found"
        IF ball is left of deadzone:
            RETURN left command
        IF ball is right of deadzone:
            RETURN right command
        RETURN walk command

    IF ball has never been seen:
        IF never-seen timeout elapsed:
            RETURN stop, giving-up message, "gave_up"
        RETURN stop, searching message, none

    IF ball was seen before but lost too long:
        RETURN stop, lost/giving-up message, "gave_up"

    SPIN toward last side where ball was seen
    RETURN left or right command, spin message, none
```

```text
            configure Realtime session
            request text output only
            provide bilingual sound-command instructions
            configure PCM input audio at 24 kHz
            enable transcription and semantic VAD
            register play_sound tool with allowed sounds
            force tool call unless environment disables it
        PRINT tool mode

    FUNCTION on_message(ws, message):
        PARSE incoming JSON event

        IF session.updated:
            MARK ready
            PRINT ready message
        ELSE IF output text delta/done:
            PRINT text diagnostic
        ELSE IF input audio transcript completed:
            PRINT transcript
        ELSE IF function-call item completed:
            handle_function_call(item)
        ELSE IF function-call arguments completed:
            build function-call item and handle it
        ELSE IF response.done:
            PRINT abnormal response status if present
            CHECK fallback output items for function calls
        ELSE IF error:
            PRINT error JSON

    FUNCTION handle_function_call(item):
        READ call_id
        IF call_id is missing or already handled:
            RETURN
        MARK call_id handled
        PARSE function arguments JSON
        sound = lowercased requested sound

        IF sound is allowed:
            TRY Bridge.call("play_test_sound", sound)
            SET tool result to played or error
        ELSE:
            SET tool result to rejected

        IF websocket is available:
            SEND function_call_output item with result
            SEND response.create so Realtime can complete the turn

    FUNCTION send_audio(pcm16):
        IF Realtime session is not ready:
            RETURN false
        IF websocket is closed or unavailable:
            RETURN false

        BASE64 encode pcm16 bytes
        SEND input_audio_buffer.append event
        RETURN true if successful

    FUNCTION close():
        CLOSE websocket if present
```

### TCP audio receiving

```text
FUNCTION read_exact(connection, size):
    CREATE empty byte buffer
    WHILE buffer length is less than size:
        RECEIVE remaining bytes from socket
        IF socket closes:
            RAISE connection error
        APPEND chunk
    RETURN bytes

CLASS AudioMonitor:
    FUNCTION init():
        RESET frame and byte counters
        RESET next report time

    FUNCTION report(pcm16):
        INCREMENT frame and byte counters
        IF not time to print:
            RETURN

        CONVERT PCM bytes to signed 16-bit samples
        COMPUTE peak and RMS levels
        PRINT frame count, bytes, dBFS level, and quiet/signal state

FUNCTION serve_esp32_audio(realtime, host, port, stop_event):
    CREATE TCP server socket
    BIND to host and port
    LISTEN for one ESP32 connection
    SET accept timeout
    CREATE AudioMonitor

    WHILE stop_event is not set:
        ACCEPT ESP32 connection if available
        WITH connection:
            LOOP until stop or stream error:
                READ 4-byte big-endian length header
                CONVERT header to frame size
                IF frame size invalid:
                    RAISE error
                READ exact PCM frame bytes
                REPORT audio levels
                realtime.send_audio(frame)
        PRINT reconnect message
```

### WAV playback

```text
FUNCTION rejectSound(sound, reason):
    CLOSE current sound file if open
    RESET remaining sound data and current sound
    PRINT NACK with reason

FUNCTION openWavSoundLocked(sound):
    IF sound is not beep, success, or error:
        reject unsupported sound
        RETURN false

    CLOSE previous sound file if open
    OPEN /sounds/<sound>.wav from LittleFS
    IF file missing:
        reject file not found
        RETURN false

    READ and validate RIFF/WAVE header
    LOOP through WAV chunks:
        IF chunk is fmt:
            READ format values
            MARK format found
        ELSE IF chunk is data:
            REQUIRE format already found
            STORE data byte count
            MARK data found
            BREAK
        SEEK to next chunk, including padding byte when needed

    IF fmt or data chunk is missing:
        reject missing chunk
        RETURN false

    IF WAV is not PCM16 mono 16 kHz or data length is odd:
        reject format
        RETURN false

    STORE current sound and remaining data length
    PRINT ACK WAV started
    RETURN true

FUNCTION openWavSound(sound):
    LOCK sound mutex
    result = openWavSoundLocked(sound)
    UNLOCK sound mutex
    RETURN result

FUNCTION readPlayCommands():
    WHILE bytes exist on Serial2:
        READ one character
        IF newline:
            TRIM accumulated UART line
            IF line starts with "PLAY:":
                EXTRACT sound
                LOWERCASE sound
                PRINT command ACK
                openWavSound(sound)
            CLEAR UART line
        ELSE IF not carriage return and line is short enough:
            APPEND character to UART line

FUNCTION pumpWav():
    LOCK sound mutex
    IF no file open or no data remaining:
        UNLOCK and RETURN

    CHOOSE up to 512 bytes to read, rounded down to whole int16 samples
    IF byte count is zero:
        reject odd sample data
        UNLOCK and RETURN

    READ bytes from WAV file
    IF read failed:
        reject read error
        UNLOCK and RETURN

    CONVERT little-endian bytes to int16 speaker samples
    WRITE samples to speaker I2S
    IF write byte count mismatched:
        reject I2S write error
        UNLOCK and RETURN

    SUBTRACT bytes read from remaining data
    IF sound finished:
        PRINT SOUND_DONE
        CLOSE file
        CLEAR current sound

    UNLOCK sound mutex

TASK soundPlaybackTask:
    LOOP forever:
        pumpWav()
        IF no sound is active:
            DELAY 2 ms
```

```text
    RETURN int16 sample

FUNCTION connectAudioStreamIfNeeded():
    IF Wi-Fi is not connected:
        RETURN
    IF TCP audio client is already connected:
        RETURN
    IF last connection attempt was less than 1 second ago:
        RETURN

    IF connected:
        DISABLE Nagle delay
        PRINT connected
    ELSE:

FUNCTION streamMicFrame():
    IF TCP audio client is not connected:
        RETURN

    READ one full frame of raw 32-bit mic samples from I2S
    IF frame incomplete:
        RETURN

    FOR each raw sample:
        CONVERT to PCM16

    WRITE 4-byte big-endian payload length
    WRITE PCM16 payload bytes
    IF client disconnected:
        STOP client
```

## End-To-End Normal Vision Pseudocode

```text
START App Lab DogVision
Arduino sketch registers Bridge handlers
Python vision app starts
CameraStream begins capturing latest frame
FaceGate loads known face database
BallTracker loads YOLO model

LOOP:
    Get latest mirrored frame

    IF in ball chasing mode:
        optionally detect point-down manual stop
        detect ball with YOLO
        send stop/left/right/walk command
        exit chasing if ball found or timeout
        update OLED
        CONTINUE

    Run hand detector periodically
    Run face detector periodically
    Update LED matrix for familiar/unfamiliar face

    IF standing, no hand, and legs-only person appears:
        start camera scan

    Update camera scan state:
        search familiar face
        scan down for hand if needed
        lock on hand
        return to neutral after target loss or timeout

    IF a hand exists:
        classify open palm, fist, or pointing direction
        IF familiar-face gate allows commands:
            map gesture and posture state to command
            send command to Arduino Bridge
            update robot state and cooldown
        ELSE:
            display unfamiliar/ignored message

    Update OLED only if text changed
```

## End-To-End Speech-Test Pseudocode

```text
ENABLE RUN_SPEECH_TEST_ONLY in python/main.py
START App Lab DogVision
Python runs speech_test.py instead of vision loop
UNO Q opens TCP server on port 3333
UNO Q opens Realtime websocket
ESP32 test firmware connects to Wi-Fi
ESP32 connects TCP audio stream to UNO Q

LOOP ON ESP32:
    read microphone frame from INMP441
    convert to PCM16
    send length-prefixed frame to UNO Q over TCP
    read any PLAY:<sound> command from UNO Q UART
    play matching WAV from LittleFS through MAX98357A

LOOP ON UNO Q:
    receive PCM frame from ESP32
    print audio levels for diagnostics
    append audio to Realtime input buffer
    when Realtime detects a sound command:
        receive play_sound tool call
        validate sound name
        Bridge.call("play_test_sound", sound)
        Arduino sketch sends PLAY:<sound> to ESP32
        send tool result back to Realtime
```
