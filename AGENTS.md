# AGENTS.md

## Project Context

This is an Arduino UNO Q project. The project is deployed and tested on the board after changes are pushed to GitHub and pulled onto the board.

## Rules

- Do not commit Wi-Fi passwords, API keys, tokens, or board-specific secrets.
- Keep changes small and explain how to test them on the UNO Q.
- Preserve existing Arduino/App Lab project structure unless asked to reorganize it.
- After code changes, check for obvious compile errors and mention any board-side test steps.
